# C 题三问本地复跑与模型审查

日期：2026-11-22  
本报告依据本机 PyCharm 项目中的独立复跑结果整理，供论文组引用结果与图片。结果只使用题目提供的数据。

## 审查结论

三个问题的代码均在本地环境成功运行，输出与此前权威结果口径一致。未发现会使当前主要结论失效的数据泄漏或计算错误；但存在需要在论文中明确写出的模型局限，不能把结果表述成模型全面优越或已通过官方测试。

## Q1：手部状态预测和观测质量

- 状态预测模型：每只手独立计算 21 个三维关键点逐坐标中位数作为位置，用六维常速度卡尔曼滤波器预测；同时报告末值保持和常速度外推基线。
- 评估划分：训练环境估计过程/观测尺度，测试环境评估；环境级 bootstrap 计算区间。
- 测试集一步 MAE：末值保持 0.0142、常速度 0.0039、卡尔曼 0.0041。h=20 时分别约 0.2460、0.1961、0.1957。
- 卡尔曼与常速度在长步长误差几乎相同，且一步误差略高；因此目前结果支持“运动外推优于末值保持”，但不支持卡尔曼显著优于常速度的强结论。
- 质量模型：逻辑回归使用运动和关键点离散度特征；测试 AUC 0.697、AUPRC 0.0268、坏帧召回率 0.140、精确率 0.048。类别极度不平衡且区分能力弱，适合作为探索性质量提示，不宜声称能可靠识别坏帧。

## Q2：遮挡下的因果回放

- 在测试集 6,447 个回放窗口上比较自适应请求、固定间隔、末值及常速度方法；每次预测仅使用当时可见帧，逐步回放 trace 抽查通过。
- 1.5 秒遮挡时，自适应 MAE/RMSE 为 0.1330/0.1964，经验覆盖率 0.892，请求比例 0.956；固定间隔 MAE 0.2420，末值 MAE 0.2631。
- 2.0 秒时，自适应 MAE 0.1637、覆盖率 0.904；固定间隔 MAE 0.2024、末值 MAE 0.3171。
- 结论限于当前离线遮挡回放及请求预算设定，不等同于真实设备部署效果。自然低质量事件共 186 个，以遮挡为主。

## Q3：带时长不确定性的任务调度

- 时长模型仅在训练集拟合，采用 family 特征的 Q50/Q90 分位数梯度提升；验证集选择策略参数，结果为验证集模拟，官方 test seeds 尚未提供，未声称通过官方测试。
- 验证集时长结果：family 中位数基线 MAE 3.4771；Q50 MAE 3.3788、pinball loss 1.6894、经验覆盖率约 0.39；Q90 MAE 9.2395、pinball loss 7.8969、经验覆盖率 0.80（名义 0.90）。分位数区间存在欠覆盖，预留时长使用混合分位策略以降低风险。
- 调度模拟共 1,350 次试验，invalid=0；同 seed、同场景、同映射配对比较，并独立重算样例指标一致。
- 使用完整 30 seed/90 次调参仿真完成两阶段搜索，选中参数与先前冻结参数一致；按该参数独立复跑 1,350 次验证试验后，Q3 准时率门槛表和完整验证汇总与仓库权威输出 SHA256 一致。
- 名义映射（α=1, β=0.5）的加权准时率：adaptive 的 S1/S2/S3 为 0.8292/0.6639/0.5604，no-review 为 0.8354/0.6528/0.5771，均达到 0.50 阈值；EDD 为 0.4208/0.2833/0.2323，未达到阈值。
- no-review 的加权准时率略高于 adaptive；若论文主张 adaptive 更实用，需要同时依据成本、观测预算等目标函数解释权衡，不能只凭准时率称其占优。
- 名义映射下 adaptive 平均成本 S1/S2/S3 为 26.94/30.44/37.68，no-review 为 23.42/25.70/31.99；adaptive 使用了 4/6/8 次观测，no-review 为 0。论文应呈现为“用额外观测换取部分场景的策略灵活性”，而非单指标最优。
- 这证明当前验证集和给定调度假设下 adaptive/no-review 达到题设门槛，不代表对未见官方测试种子泛化已验证。论文需如实报告 EDD 失败和 Q90 欠覆盖。
