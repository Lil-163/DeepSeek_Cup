# C 题三问本地复跑与模型审查

日期：2026-11-22  
本报告依据本机 PyCharm 项目中的独立复跑结果整理，供论文组引用结果与图片。结果只使用题目提供的数据。

## 审查结论

三问均已在官方题目数据上本地全量运行。代码审查发现并修复了 Q3 复核决策与候选顺序绑定的问题；同时采用 Joseph 形式更新卡尔曼协方差、补齐 Q1 两个噪声参数的环境级不确定性，并为 Q2 增加测试环境分组结果。修复后 Q1/Q2 全量重跑，Q3 完成完整调参和 1,350 次验证重跑；没有发现题目约束违规或回放信息泄漏。结论仍有模型与验证范围限制，不能声称所有模型都占优或已通过官方测试。

## Q1：手部状态预测和观测质量

- 状态预测模型：每只手独立计算 21 个三维关键点逐坐标中位数作为位置，用六维常速度卡尔曼滤波器预测；同时报告末值保持和常速度外推基线。
- 评估划分：训练环境估计过程/观测尺度，测试环境评估；环境级 bootstrap 计算区间。
- 加速度残差方差估计 6.246（训练环境 bootstrap 95% CI：3.859–8.437）；观测噪声方差尺度估计 1.308×10⁻⁶（95% CI：7.941×10⁻⁷–1.804×10⁻⁶）。卡尔曼协方差使用 Joseph 更新形式。
- 测试集一步 MAE：末值保持 0.0142、常速度 0.0039、卡尔曼 0.0041。h=20 时分别约 0.2460、0.1961、0.1957。
- 卡尔曼与常速度在长步长误差几乎相同，且一步误差略高；因此目前结果支持“运动外推优于末值保持”，但不支持卡尔曼显著优于常速度的强结论。
- 质量模型：逻辑回归使用运动和关键点离散度特征；测试 AUC 0.697、AUPRC 0.0268、坏帧召回率 0.140、精确率 0.048。类别极度不平衡且区分能力弱，适合作为探索性质量提示，不宜声称能可靠识别坏帧。

## Q2：遮挡下的因果回放

- 在测试集 6,447 个回放窗口上比较自适应请求、固定间隔、末值及常速度方法；返回信息索引和一秒延迟复核无违规。按四个测试环境作配对汇总，adaptive 在 1.5 秒与 2.0 秒遮挡下的 MAE 均在四个环境中低于固定间隔，属于描述性一致性（测试环境仅 4 个，不作显著性推断）。
- 1.5 秒遮挡时，自适应 MAE/RMSE 为 0.1330/0.1964，经验覆盖率 0.892，请求比例 0.956；固定间隔 MAE 0.2420，末值 MAE 0.2631。
- 2.0 秒时，自适应 MAE 0.1637、覆盖率 0.904；固定间隔 MAE 0.2024、末值 MAE 0.3171。
- 结论限于当前离线遮挡回放及请求预算设定，不等同于真实设备部署效果。自然低质量事件共 186 个，以遮挡为主。

## Q3：带时长不确定性的任务调度

- 时长预测模型仅使用训练环境数据拟合。为修正 Q90 欠覆盖，按 16 个训练环境逐环境留出，得到 738 条 OOF 预测；非负加法校准量为 3.858971 秒，训练 OOF 覆盖率由 0.8157 提升到 0.8997。验证集只用于策略参数选择和结果评估，没有加入外部训练数据。
- 验证集时长结果：family 中位数 MAE 3.4771；Q50 MAE 3.3788、pinball 1.6894、覆盖率 0.3905；原始 Q90 MAE 9.2395、pinball 7.8969、覆盖率 0.8000；校准 Q90 MAE 12.2143、pinball 10.9279、覆盖率 0.9524（21 条中 20 条）。校准纠正欠覆盖，但在该小验证集上偏保守，论文应报告此取舍。
- 两阶段参数搜索只在验证集名义映射（α=1, β=0.5）上调参，选出 w_due=1.0、w_cost=0.06、reserve_quantile_mix=0.5（其余见 q3_tuned_params_flat.json）。
- 最终验证共 1,350 次试验（3 场景 × 5 时长映射 × 30 seeds × 3 策略），invalid=0；逐动作日志共 11,580 行。对 seed=2026111700/S1/adaptive/α=1.0/β=0.5 的独立重算，11 项指标逐项一致。
- 名义映射（α=1, β=0.5）30 seeds 平均加权准时率：

| 场景 | adaptive | no-review | EDD |
|---|---:|---:|---:|
| S1 | 0.7917 | 0.8271 | 0.3813 |
| S2 | 0.6097 | 0.6236 | 0.2722 |
| S3 | 0.5073 | 0.5250 | 0.2135 |

- 对五种时长映射、30 seeds 汇总后的平均加权准时率：

| 场景 | adaptive | no-review | EDD |
|---|---:|---:|---:|
| S1 | 0.7925 | 0.8113 | 0.3750 |
| S2 | 0.5872 | 0.6019 | 0.2628 |
| S3 | 0.5004 | 0.5219 | 0.2135 |

adaptive 与 no-review 在名义映射三场景均达到 0.50 均值门槛；五映射汇总中 adaptive 的 S3 为 0.5004，接近门槛。no-review 的准时率在三场景均高于 adaptive，adaptive 成本也更高，因此不应声称 adaptive 全面占优。EDD 三场景均未达到门槛。
- 官方 test seeds 尚未提供；以上均为验证集调参与验证结果，不代表独立测试表现。完整参数、指标、过程日志和校准诊断见 outputs/paper_ready_20261122/ 与 reports/q3_calibrated_rerun_review_20261122.md。
